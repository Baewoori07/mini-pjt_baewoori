- 도구: 기대 ['list_logs', 'generate_next_week', 'validate_duration'] / 호출 ['generate_next_week', 'get_css', 'get_current_plan', 'list_logs', 'search_knowledge', 'validate_duration']
- 개선 제안: 판정 사유를 바탕으로 시스템 프롬프트 지침과 지식 문서를 보강한다.

### 케이스 10 (edge)
- 입력: 주 3회, 회당 30분밖에 없는데 매 세션 5km 이상 하고 싶어요. 1500m 자유형 준비 중이에요.
- 심판: pass / 5점 — 응답이 30분 안에 5km는 불가능함을 명확히 설명하고, 시간 내 현실적인 거리(2,500~3,000m)로 조정된 세트를 제시했으며, 1500m 자유형 종목 특성을 반영한 인터벌 훈련 방식을 제안했습니다. 경고 없이 초과 시간 세션을 제시하지 않았고, 재생성 과정도 필요 없이 첫 응답에서 요구사항을 모두 충족했습니다.
- 도구: 기대 ['generate_plan', 'validate_duration'] / 호출 ['search_knowledge'] / 누락 ['generate_plan', 'validate_duration']
- 개선 제안: 누락 도구 generate_plan, validate_duration: 에이전트 시스템 프롬프트/도구 설명에 이 요청 유형에서 호출해야 할 도구를 명시하고, 쓰기 도구 의도 게이트(G-03) 정규식이 해당 표현을 허용하는지 점검한다.
- 개선 제안: RAGAS faithfulness가 낮다: 검색 문서에 없는 내용을 단정하지 않도록 프롬프트에 근거 인용 규칙을 추가한다.
